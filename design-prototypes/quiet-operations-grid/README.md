## 第 1 批生成口径

- 生成方式：Codex 内置图片生成
- 画布：1440 × 1024
- 日期锚点：2026-07-22
- 登录页提示词：以母版和现有登录页为参考，保留账号、密码、登录按钮、产品名称和三个真实系统范围标签；不增加第三方登录、找回密码或营销内容。
- 首页概览 V1 提示词：以母版和现有概览页为参考，只保留六个现有统计字段、刷新、用户管理和五个快速入口。经评审，该版本运营信息不足，状态调整为“需修订”。
- 首页概览 V2 提示词：在母版浅色外框内增加现有分析接口可支持的时间、区域和 HIS 机构筛选，四项核心运营指标、服务趋势、功能调用分布，并将六个既有统计字段收敛为“基础资源”次级数据条；不增加令牌筛选、全局搜索、通知中心、审批待办或新的后台接口。
