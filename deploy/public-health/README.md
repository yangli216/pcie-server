# 公卫生产契约交付

两项独立能力：随访健康处方 `health_prescription` 与智能减重助手 `weight_management`。远端接入见[API.md](../../API.md)，跨端产品/接口章节见[公卫设计](PUBLIC_HEALTH_DESIGN.md)，机器契约见 `contracts/`。JSON 与工作区 `development-harness/contracts` 协同版本逐字节同步；设计保留生产契约章节并调整交付链接。

包含公卫 OpenAPI、检查计划/健康教育内部模型 Schema 和合成接口示例。调试入口、诊断面板、截图、运行过程记录及未批准资产取回文件不随功能分支提交；生产单元测试使用 Fake 模型隔离外部调用。

服务端默认关闭，正式运行需运行表、签名设备、机构批准的规则/Prompt/食谱向量与 manifest。缺配置或资产时明确阻断，不发布本机参考规则，不接入 WeKnora 公开测试集合。离线索引工具用法见[HARNESS.md](../../HARNESS.md#公卫知识索引工具)，输入由实施方显式提供，模型密钥仅使用服务端环境变量。
