## 流程与验收

1. BBP管理员或已授权医务科质控员按日查询，默认全部，也可选择草稿/已完成；显示独立病历状态列。
2. 查询/翻页自动分批处理当前页，100条分两批，最多5并发；每次新查询 force=true。计算期间不显示上一次分数，完成后展示本次分数/问题，失败有明确提示。
3. 草稿多次保存后重新查询应读取最新正文，同问题只出现一次；补齐主诉后旧问题不再出现在当前分析。分析期间正文发生变化返回409，不保存过时分析；跨系统仍无法保证核验后的PHIS不再修改。
4. 翻页/重查隔离迟到响应；已有服务端任务继续完成，但已失效查询的后续批次不再启动。刷新恢复任务但不自动新建；完成任务、详情返回与人工调整刷新不重复计算。新查询仍受单管理员一个任务限制，BUSY提示等待。
5. 已完成病历采用同一v6九维100分评分输入与提示词，固定模型响应下得分保持一致。普通医生、单独ORG_ANALYST及跨机构/跨会话访问仍拒绝。
6. 失败不落部分记录/发现；成功审计与结果写入共用事务。不保存正文/HTML/XML、不向AI发送身份或Cookie，不回写PHIS。
